# SkyNav Sim (Flught_Simulator)

A web-based avionics navigation flight simulator for VOR, DME, ADF, ILS, INS/GPS and the glass cockpit.
It is one Nuxt 4 app (Vue 3 + Nitro), with Prisma and PostgreSQL.
